# Contributing

Thanks for helping improve these skills.

## Ways to help
- **Report a problem:** open an issue with the skill name, what you asked Claude, what happened, and what you expected.
- **Suggest a change:** open an issue first for anything big, so we can agree on the direction.
- **Send a pull request:** fix a typo, tighten an instruction, or add a reference file or script.

## Pull request guidelines
1. Fork the repo and create a branch from `main`.
2. Keep each skill in `skills/<skill-name>/` with a `SKILL.md` that has `name` and `description` in its front matter.
3. Change one skill per pull request when you can.
4. Don't add API keys, personal file paths, or copyrighted media.
5. Explain what changed and why in the pull request description.

## Style
- Write instructions as short, direct steps.
- Put long background material in `references/`, not in `SKILL.md`.
- Test the skill in Claude Code before you submit.
